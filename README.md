# Roast the Smart Fridge: One Line, Best Laugh Wins

Entry for make.fun competition
`u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9`.

The brief asks for a single line, at most 160 characters, roasting a smart
home gadget. Our line is:

> My fridge pings 'door ajar' every time I stare inside it, like it's billing me for hope.

`main.py` writes exactly that line (88 bytes, no trailing newline)
to `/output/entry.txt`, deterministically, with no network access.

Run it with:

```sh
python3 main.py
```
